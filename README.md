# 桌面歌词

在 macOS 菜单栏左侧的空白处显示当前歌曲的歌词，跟随播放进度逐字高亮。不挡任何窗口，鼠标点击会直接穿透。

支持 Apple Music、QQ音乐，以及其他会出现在控制中心“正在播放”里的播放器（比如浏览器里的飞牛音乐网页）。歌词来自 QQ音乐和 [LRCLIB](https://lrclib.net)：QQ音乐播放的歌和中文歌先查 QQ音乐，其他先查 LRCLIB，查不到再换另一个。

## 环境要求

- macOS 13 或更高版本
- 苹果命令行工具（不需要 Xcode）：在终端运行 `xcode-select --install`
- 建议在“系统设置 > 控制中心 > 自动隐藏和显示菜单栏”里选“永不”，这样全屏应用里也能看到歌词

## 安装

```bash
git clone https://github.com/Allen-1002/desktop-lyrics.git
cd desktop-lyrics
./scripts/install.sh
```

会编译并装到“应用程序”文件夹，名字叫“桌面歌词”，之后可以从启动台或聚焦搜索打开。第一次安装会要求输入登录密码（用来创建签名证书）。在 ♪ 菜单里勾选“登录时自动打开”，开机后就会自己启动。

更新：`cd desktop-lyrics && git pull && ./scripts/install.sh`

封装成 dmg 安装包：`./scripts/make-dmg.sh`，生成 `build/桌面歌词-<版本>.dmg`，打开后把“桌面歌词”拖进“应用程序”。这个安装包用本机证书签名，在别的 Mac 上第一次打开要右键选“打开”。

只想编译不安装：

```bash
./scripts/setup-signing.sh   # 只需第一次运行
./scripts/build-app.sh
open build/DesktopLyrics.app
```

`setup-signing.sh` 会在钥匙串里创建一个本机自用的签名证书。有了它，每次重新编译后系统仍然认得这个应用，不用重新授权。

## 第一次运行需要的权限

1. **控制“音乐”**：第一次读取播放信息时系统会弹窗，点“好”。用来读取歌名和播放进度。
2. **辅助功能**：系统会提示去“系统设置 > 隐私与安全性 > 辅助功能”里打开“桌面歌词”。用来读出当前应用的菜单有多宽，让歌词紧跟在菜单后面。不开也能用，歌词会固定放在屏幕宽度约 25% 的位置。

> 没有运行 `setup-signing.sh` 时，每次重新编译后系统会把它当成新应用，需要在辅助功能列表里删掉旧的再重新添加。

## 排查问题

在终端里直接运行可执行文件，可以看到每一步的日志（播放信息、歌词查找结果、显示位置）：

```bash
./build/DesktopLyrics.app/Contents/MacOS/DesktopLyrics
```

按 Ctrl+C 退出。从终端运行时，系统按“终端”App 的辅助功能权限判断，所以日志里可能显示“未开启”；平时用 `open build/DesktopLyrics.app` 启动即可。

## 使用

菜单栏右侧会多一个 ♪ 图标，点开可以：

- **歌词提前 / 延后 0.5 秒**：歌词和声音对不上时调整，每首歌单独记住
- **重新获取歌词**：歌词版本不对时重新下载
- **字号**：小 / 中 / 大 / 特大
- **文字颜色**：跟随系统、几种预设颜色，或自定义任意颜色
- **背景**：无 / 深色底 / 浅色底，壁纸花哨时加一层半透明底更清楚
- **隐藏歌词**
- **登录时自动打开**（需要先用 install.sh 安装）
- **退出**

暂停 3 秒后歌词会自动隐藏；没找到歌词时显示歌名和歌手。

## 工作方式

| 部分 | 做法 |
|---|---|
| 播放信息 | Apple Music：每 0.5 秒用 AppleScript 读取歌曲和播放位置，切歌、暂停时通过系统通知立即刷新。其他播放器：读取系统“正在播放”信息。macOS 15.4 起普通应用读不到这份信息，所以由系统自带的 `/usr/bin/perl` 加载 `libNowPlayingHelper.dylib` 来读（做法参考 [mediaremote-adapter](https://github.com/ungive/mediaremote-adapter)） |
| 同步 | 两次读取之间在本地推算播放时间，偏差超过 0.25 秒才校准，画面每秒刷新 30 次 |
| 歌词 | QQ音乐：按“歌名 + 歌手”搜索，挑歌手对得上、时长相差 4 秒内的那首；LRCLIB：先精确查询，没有再模糊搜索。结果缓存在 `~/Library/Application Support/DesktopLyrics/Lyrics` |
| 逐字高亮 | LRC 只有每行的开始时间，按字数估算演唱时长来推进高亮 |
| 显示位置 | 一个透明、点击穿透的窗口盖在菜单栏上，位于当前应用菜单的右边；屏幕右侧 38% 留给系统图标 |

## 已知限制

- 读取系统“正在播放”信息依赖私有接口，以后的 macOS 更新可能让它失效，届时只剩 Apple Music 可用
- 浏览器里放视频时也会尝试找歌词，找不到就不显示
- QQ音乐歌词接口不是官方开放的，以后可能失效
- 菜单特别多的应用里，左侧空间不够时歌词会被截断或隐藏
- 多显示器时只显示在主显示器的菜单栏上
